# vision — AI 비전

담당: **D (승준, @5Color)**

카메라 3대의 영상으로 컵을 인식합니다. 모델은 [5Color/dtra](https://github.com/5Color/dtra) `v3.1.0`을 사용합니다. 모델 코드는 이 저장소에 복사하지 않고 태그로 버전을 고정해 씁니다.

| 카메라 | 역할 |
|---|---|
| CAM 1 상단 웹캠 | 벨트 전체, 컵 위치·분포·밀집도 |
| CAM 2 로봇팔 카메라 | 컵 위치·자세, 로봇팔 기준 좌표 |
| CAM 3 작업 위치 카메라 | 컵 도착 감지 |

## 모델 요약

- 고정된 ResNet 백본 + 물체별 기억 슬롯. 샘플 몇 장과 자연어 라벨로 등록하고, 등록이 끝난 슬롯은 잠근다.
- 배경·조명을 빼고 윤곽선 유사도로 판별: 기준선 안 → 음료 컵(뚜껑 유/무, 집을 위치), 밖 → 기타 쓰레기(통과).
- 컵 하나가 끝날 때마다 상태 초기화. 로봇팔 궤적도 B-spline으로 생성 가능.
- 자세한 설명은 [README 5절](../README.md#ai-비전-모델--dtra-v31).
